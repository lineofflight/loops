In Herdr, the Loops drawer lists the session’s open loops. Each ring fills as its loop waits, amber after a day and coral after three. Hover or tap a loop to dismiss it.

Any agent

One small binary. loops mcp serves the ledger over stdio to Claude Code, Codex, Antigravity or any other MCP client.

Brings its own instructions

The server tells the agent when to record a loop and when to close it. No edits to AGENTS.md.

Follows the session

Each agent session has its own ledger. Resume it anywhere and its loops are still there. A new session starts empty.

Works from the shell

loops add, loops done and loops list do the same from any terminal.

Add it to your agent

claude mcp add loops -- loops mcp

Other agents take the same command, loops mcp. The README covers Codex, Antigravity, the Herdr drawer and building from source.
