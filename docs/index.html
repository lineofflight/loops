loops

An open loops ledger for coding agents.

Keeps unanswered questions, pending choices and parked ideas from getting buried when a conversation pivots.

Source on GitHub 
$ loops add "Linter: ESLint or Biome?"
1. Linter: ESLint or Biome?
$ loops add "Add evals for the date parser"
1. Linter: ESLint or Biome?
2. Add evals for the date parser
$ loops done 1
1. Add evals for the date parser

For any agent

One small binary. loops mcp serves the ledger as MCP tools over stdio, to Claude Code, Codex, Antigravity or anything else that runs such a server.

Teaches itself

The server sends its instructions when it starts, so an agent learns when to record a loop and when to close it without edits to its AGENTS.md.

Follows the session

A ledger belongs to the agent session. Exit and resume it anywhere, and its loops are still there. A new session starts with none.

Optional UI

Inside Herdr, a Loops drawer lists the session’s open loops, shows how long each has waited, and dismisses one with a click.

Install

cargo install --git https://github.com/lineofflight/loops
claude mcp add loops -- loops mcp

Other agents take the same command, loops mcp. The README has the rest.
